## 2. 投稿構造のパターン

### **パターンA：問題提起 → 原因解析 → 解決提示**
```
現在の問題状況を描写
　↓
その問題が起きる根本原因を説明
　↓
自分たちの解決方法・視点を提示
　↓
（暗黙の）来店・相談への流れ
```
**例：** 「細胞にムチを打つだけのダイエットは無理→細胞を喜ばせる→1回10円のアクション」

### **パターンB：成果実績 → 複数の効果列挙 → 継続理由への言及**
```
お客様の声（結果）
　↓
複数の改善項目を箇条書き的に提示
　↓
それが可能になる理由（コース内容など）
　↓
（暗黙の）来店促進
```
**例：** 「7キロ痩せた→ジーパン・シミ・むくみ・体の軽さ→継続ルルオンで変わる」

### **パターンC：従来 vs 革新の対比構造**
```
業界の旧来の方法（デメリット記述）
　↓
新しい自社メソッド（優位性強調）
　↓
その結果得られる体験
```
**例：** 「10年前のピーリング=悲惨な剥離→最新ピーリング=気持ちいい+マッサージ可能」

### **パターンD：個人的な失敗 → 気づき → 解決法の発信**
```
過去の試行錯誤（5年失敗など）
　↓
その経験から見えた「本質」を言語化
　↓
これからの発信予告
```
**例：** 「リバウンド失敗→心の変化が見えた→これから発信していく」

## 3. 反応されそうな感情のツボ

| 感情 | 具体的な表現方法 | 投稿数 |
|------|-----------------|--------|
| **共感・被認識感** | 「こんなの探してた」「我慢できないから言うけど」「あるある」を誘う表現 | 多い |
| **安心感・信頼感** | 複数の改善実績を数字で並べる、医学的根拠（ホルモン・腸内環境等）を述べる | 多い |
| **希望感・可能性** | 「細胞レベルで」「1回10円」「30秒」など簡便性を強調 | 多い |

| **自己肯定感の回復** | 「自分を責めるのは終わりにして」「体の中の細胞たちと一緒に」など労わり表現 | 少数だが印象的 |
| **親近感・人間らしさ** | 失敗談・葛藤・試行錯誤の過程を正直に語る | 少数だが高反応 |
| **焦燥感・危機感** | 「更年期で体重増加」「3ヶ月で白髪増加」など加齢による変化への警告 | 中程度 |

## 4. CTA・誘導のパターン

### **パターン①：直接的なCTAなし（暗黙的信頼誘導型）**
```
「継続ルルオンで体は変わる！！」
→ プロフィール経由で来店・DM へ
```
- サロン紹介投稿に多い
- 信頼醸成を優先

### **パターン②：問い返しで参加促進型**
```
「こんな経験ある人いない？」
「皆さんは、家の中で『ここが一番片付かない…！』という場所はどこですか？」
→ コメント・引用リツート促進 → フォロー → DM
```
- エンゲージメント最大化
- 継続フォロー誘因

### **パターン③：続きが気になる予告型**
```
「効果を最大限引き出す飲み方・使い方は、、、」
「たった1つお願いがあって、」
→ 返信・フォロー待ち → DM誘導の準備
```
- シリーズ化による継続フォロー
- 次投稿への期待値上昇

### **パターン④：ハッシュタグ＆フォロー明示型**
```
#ハーブピーリング #剥かないピーリング #エステサロン開業 #大阪エステ
```
- 検索流入・同業者・見込み客のセグメント化
- SEO的アプローチ

### **パターン⑤：ストーリー化・連続投稿誘導型**
```
「これからの発信予告」
「まずは骨盤の角度とカラダの重心を調整。」
→ 次の投稿で詳細 → フォロー継続
```
- 時系

## 2. 投稿構造のパターン

### パターンA: **課題発見→具体的実装→成果報告**
```
1. 問題認識（「こういう悩みがあった」「〜と言われた」）
2. 実装内容の詳細（「AIを使ってこうした」）
3. 結果（定性的メリットを述べる）
```
**例：** 「求人で優位性がないと思っていた」→「AIに強いサロンになる」→「求職者の興味が変わった」

---

### パターンB: **業界警告→二極化の示唆→行動促進**
```
1. 業界全体の課題（「固定費が首を絞める」「AIで消える職業」）
2. 対比的な視点転換（「消える人は、なくてもいずれ消えていた」）
3. 今すぐ取るべき行動（「効率化が肝」）
```
**例：** 「多数スタッフ抱える時代は終わり」→「身軽な経営が必須」→「AIを織り込むしかない」

---

### パターンC: **実装の詳細→理由の論理化→理念への昇華**
```
1. 具体的な取り組み内容（「朝礼をAIが司会」「音声メモが自動反映」）
2. その理由・仕組み（「〇〇だからこう設計した」）
3. 理念とのつながり（「患者様への提供価値を語る」）
```

---

### パターンD: **悩み共有→相互作用への誘い**
```
1. 課題の段階的説明（「ベテランスタッフが反発する」）
2. 一般的な失敗パターン（「お金や効率では説得できない」）
3. 正解の提示（「理念と結びつける」）
```
